# SoftDev Corporate Homepage

This is a simple, modern, responsive homepage built with React.js for a software development company.

## Features

*   **Responsive Design:** Works beautifully on desktop and mobile devices.
*   **Clean Architecture:** Built using reusable React components.
*   **Plain CSS:** Styled completely with plain CSS (no external libraries like Tailwind or Bootstrap).
*   **Key Sections:** Includes a Navbar, Hero section, Services section with 3 cards, and a Footer.

## Requirements

*   Node.js (v16.0.0 or higher recommended)
*   npm (v7.0.0 or higher)

## Installation

1.  Clone the repository or download the project files.
2.  Navigate to the project directory in your terminal.
3.  Run the following command to install the necessary dependencies:

    ```bash
    npm install
    ```

## Running the Application Locally

1.  After the dependencies are installed, you can start the development server by running:

    ```bash
    npm run dev
    ```

2.  This will typically start the application on `http://localhost:5173/`. Open this URL in your web browser to view the homepage.
    (If port 5173 is in use, Vite will automatically select another available port. Check the terminal output for the correct URL.)

## Building for Production

To create a production-ready build, run:

```bash
npm run build
```

This will generate a `dist` folder containing the optimized assets.
